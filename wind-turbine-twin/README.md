托塔天王风电混塔数字孪生平台 · 多风机大屏版 v8.3
================================================
只需 4 步：

第1步：把 Rhino 导出的风机模型放进 models 文件夹
       （叫 F12_turbine.glb 最好，其他名字也能自动识别）

第2步：用 VS Code 打开本文件夹（文件 → 打开文件夹）

第3步：右键 index-local.html → Open with Live Server
       （推荐离线版；在线版 index.html 需联网）

第4步：浏览器打开 → 实心地形土块 + 蓝天白云 + 10 台风机 = 成功

【v8.3 新功能】（本轮：巡检/统计板块全面完善）
1. 统计页：新增「全场汇总 / 单机明细」双视图切换
   - 全场汇总 = 全场 12 个月发电量柱状图
   - 单机明细 = 选中风机的发电曲线（联动下拉/点击切换）
2. 巡检页：升级为完整巡检工作流
   - 顶部巡检汇总条：本轮巡检 10/10 完成 · 正常/异常计数
   - 巡检表升级：巡检项 | 型号 | 量程 | 实时值 | 判定 | 巡检结果 | 巡检时间
   - 超限项自动标记"需人工复核"
3. 实心地形：顶面卫星影像+DEM起伏 + 250m 厚侧面土壁 + 土层底部
4. 真实天空：Preetham 大气散射 + 程序化云层漂移

【原有功能】
- 10 台风机独立叶片旋转/传感器/告警，点击风机或下拉切换
- 顶部告警横幅带机号（F03-锚索张力超限），告警风机变红
- 总览指标卡：风机总数/运行台数/告警台数/平均风速
- 全场状态饼图动态更新

【真实数据接入（表格文件）】
看「数据接入模板」文件夹：示例CSV → convert_csv.py → data.json

【调试工具（控制台 F12）】
- 空格键：暂停/恢复叶片旋转
- setBladeAxis("x"/"y"/"z")：切换叶片旋转轴

【常见问题】
- 页面空白？→ 必须用 Live Server 打开，不能双击文件
- 控制台 404 F12_turbine.glb / favicon.ico → 无害，忽略
