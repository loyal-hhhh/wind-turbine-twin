■ v9 新功能（对应老师 6 条指导）
────────────────────────────────────────────
1. 点位级监测序列（实测 + 预测）
2. 随机机位布局（固定种子，刷新不变）
3. 监测重点转向结构健康（功率仅作观测之一）
4. 全场风机状态分布移到右侧饼图
5. 超限 → 结构影响 → 寿命：14 段杆单元计算 + 逐杆件校核表
6. 点击/选择某台 → 放大 + 显示监测数据（光环+名牌聚焦标记）

■ 数据接入（真实数据替换模拟数据）
  打开 js/data.js 顶部，把 setInterval 里的模拟值替换为真实接口：
    const res = await fetch('http://你的服务器/api/sensors')
    res.json() → 直接填入各测点 pushPoint(p, value)
  每个测点格式：{ val: 当前值, hist: [最近40个历史值] }
  也可用 数据接入模板/ 里的 CSV 转换脚本

■ 调试工具（F12 控制台输入）
  focusTurbine(3)               —— 手动聚焦第3台
  exitFocus()                   —— 退出聚焦
  computeStructure(22, 0.5)     —— 手动算结构响应（22m/s 强风+锚索超限）
  空格键                        —— 暂停/恢复叶片旋转

■ 常见问题
  Q: 控制台有 404？
  A: F12_turbine.glb 与 favicon.ico 的 404 是容错机制在试文件名，无害。
  Q: 出现红色报错？
  A: 一定是 js 文件夹里有旧文件混入。删掉整个 wind-turbine-twin 文件夹重新解压。

■ 结构力学模型说明（答辩可讲）
  塔体：混凝土段 104.7m + 过渡段1.8m + 钢段27m，总高138.1m
  简化：14 段环形截面杆单元，悬臂固接
  荷载：机舱 2500kN + 叶片推力(0.5ρv²A·Ct) + 塔身风载
  校核：σ=N/A+M/W ≤ 容许应力；位移 ≤ H/100=1381mm；寿命 25 年递减
  注：钢段顶径 3.2m、壁厚 0.35/0.18m 为估算值，拿到真实壁厚可在
      js/structure.js 顶部 GEOM 里替换
