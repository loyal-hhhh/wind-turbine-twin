【v12.0 更新说明】损伤识别模块（传感器实测 → 损伤定位 → 寿命预测）
  ① 新增"损伤识别"模式（环段损伤分析面板内 Tab 切换）：
     → 数据：每台风机实时输出 实测基频 f_m + 分布式应变阵列
       实测剖面 ε_m(z)（沿高 13 测点，含传感器噪声 ±2%）
     → 原理：损伤段刚度退化 B(z)=B0(z)(1−d) 使该段应变局部放大
       1/(1−d)——实测应变比剖面 ε_m/ε0 在损伤段出现峰值，
       配合实测基频下降辅助约束
     → 算法：加权最小二乘网格搜索 (a,d)（41×19 网格），
       误差 = 0.7·Σ(应变比偏差)²/N + 0.3·(频率比偏差)²
     → 输出：识别损伤起点 â / 退化率 d̂ / 不确定区间 /
       拟合误差 / 识别损伤下的剩余寿命（标准工况 12m/s 评估）
     → 联动：识别值自动同步到正向分析滑块、3D 红色损伤警示环
       与寿命预测结果卡
  ② 演示数据：F07 塔底严重损伤（a=20m, d=0.50）、
     F05 中部轻微损伤（a=70m, d=0.20），其余健康；
     实测数据含噪声，识别精度：位置误差 ≤5m、退化率误差 ≤0.05
  ③ 健康判定：退化率 <0.08 或解不唯一（候选点 >40）→ 未检出损伤
  ④ 页面布局：四页导航（总览 / 结构监测 / 数据分析 / 设备巡检），
     正向分析滑块 + 三条曲线保留在"结构监测"页

【v10.0 更新说明】环段损伤分析模块（经典梁理论）
  ① 新增"环段损伤分析"面板（左栏杆系力学响应下方）：
     → 模型：变截面悬臂梁（Euler–Bernoulli），塔底固接，钢/混连续
     → 损伤：环段局部抗弯刚度退化 B(z)=B0(z)·(1−d)，可调
       损伤起点 a / 损伤长度 ℓ / 退化率 d / 阻尼比 ζ / 激励频率
     → 输出：位移比 δd/δ0（单位荷载法）、频率比 fd/f0
       （Rayleigh–Ritz 单模态）、动力放大 DAF、钢段焊缝应力范围、
       年疲劳消耗（S–N：Δσ³·N=C · Miner）、剩余寿命
     → 三条分析曲线：位移比-损伤位置 / 频率比-退化率 /
       动力放大-激励频率（完整塔 vs 损伤塔）
  ② 3D 损伤高亮：聚焦任意风机时，塔身损伤环段处显示红色警示环
     （半透明罩壳 + 上下两道呼吸闪烁环线），随滑块参数联动
  ③ 方法依据《风电混塔环段损伤后的响应与疲劳分析》（苗鹏勇 2026.10.23）：
     - 静定弯矩与损伤无关（降低 EI 只改变曲率与位移）
     - 损伤越靠近塔底，塔顶柔度增幅越大（算例：ℓ/H=0.05、d=0.30，
       塔底损伤位移比 1.0611；a/H=0.80 仅约 1.0020）
     - 频率比 ≈ √(kd*/k0*)；损伤使频率降低，但风振响应增减取决于
       激励频率与固有频率的距离，不能预设必然放大
     - 疲劳评价对象＝钢段底部焊缝，Δσ 为应力范围（非半幅），
       年疲劳消耗 Dyr=n/N（N=C/Δσ^m），寿命比≈Rσ^(−m)
  ④ 保留 v9.16 全部功能（实时 14 段杆系校核、聚焦巡航、名牌一次、
     真实地形、巡检/统计页）

========== v14（AI 智能反演版）更新说明 ==========
1. 新增 AI 代理模型反演模块（js/ai_model_v14.js）：
   - 模型：MLP 神经网络 18→96→96→2，由力学正演模型批量生成 6355 组样本（a×d 全网格×噪声增强）在 Python 端离线训练，权重固化到前端，浏览器内毫秒级推理（实测单次 0.6~1.2ms）。
   - 输入特征：13 测点应变比剖面 + 峰值高度/位置/剖面平坦度 + 基频比（共 18 维）。
   - 输出：损伤起点 a(m)、退化率 d；寿命按标准工况 12m/s 评估（与力学反演口径一致）。
   - 健康判定：剖面峰值信噪比门限（rmax<0.08），与力学低退化率判据（dHat<0.10）统一，避免 ±2% 传感器噪声下误报。
2. 结构监测页识别面板新增「AI 代理模型快速反演」对比卡片：
   - 显示 AI 反演的损伤起点/退化率/剩余寿命，与力学网格反演并排对照；
   - 通道一致性判定（Δa<12m 且 Δd<0.12 → "双通道一致"，否则提示复核）；
   - 实时自动识别模式下同步更新 AI 结果。
3. 训练数据与脚本保留在 ai_train/ 目录（可复现：gen_data.js 生成数据 → train_np.py 训练导出权重）。
4. 精度（测试集）：损伤场景定位误差约 2~6m（演示 F05/F07 实测误差 2~6m），退化率误差约 0.01~0.05；健康机 100% 正确识别。
5. 答辩口径：物理力学反演（网格搜索最小二乘）与 AI 代理模型（神经网络快速推理）双通道互校，交叉验证损伤识别结果。
